## 2. What Went Well (Successes)

**Charlie (Senior Dev):** "The **Security Architecture** is solid. We stuck to the 'Fail-Closed' principle. If you don't have a token, you don't get data. Period. The `JwtAuthGuard` and `RolesGuard` on the backend are working seamlessly with the `ProtectedRoute` on the frontend."

**Elena (Junior Dev):** "I loved how we refactored the UI components. The `InvitationsTable` logic was easily reused for `UsersTable`. Those shared `RoleBadge` and `StatusBadge` components saved me a ton of time in Story 17-9."

**Dana (QA):** "And the `AuthContext` implementation. It handles the 401 token refresh automatically. I tried to break it by letting my token expire, but the interceptor caught it and refreshed it in the background. nice work."

## 3. Challenges & Critical Discoveries

**Bob (Scrum Master):** "It wasn't all smooth sailing though. Where did we stumble?"

**Dana (QA):** "We need to talk about **Testing**. We deferred unit tests for almost all the UI components (Stories 17-5 to 17-10). The `UseAuth` and `useNavigate` hooks were a nightmare to mock effectively with our current setup."

**Charlie (Senior Dev):** "Yeah, that's on me. The integration of React Router v7 with our testing library caused more friction than expected. We made a decision to push forward with manual verification to keep velocity up, but we've accrued some **Testing Debt** there."

**Elena (Junior Dev):** "Also, Story 17-1. I still can't run the backend unit tests locally because of those `npm install` authentication errors. It's weird because the CI passes, but my local environment is blocked."

**Alice (Product Owner):** "There was also a small misalignment on the Registration flow. Frontend expected a separate 'Verify Token' endpoint, but Backend just decoded it. We fixed it, but better API contracts upfront would have saved a round trip."

## 4. Key Insights & Lessons Learned

**Bob (Scrum Master):** "So, what are the takeaways?"

1.  **Mocking Strategy is Critical:** We can't just 'figure out' testing complex contexts mid-story. We need a defined pattern for mocking Auth and Router contexts *before* we start the next UI-heavy epic.
2.  **Shared Components Pay Off:** The investment in generic `DataTable` and `Badge` components in Story 17-8 allowed Story 17-9 to be finished in half the time.
3.  **RBAC Complexity:** Managing roles on both Frontend (for UI hiding) and Backend (for actual security) requires rigorous discipline. We did well this time by using a shared `roleHelpers.ts` utility.
