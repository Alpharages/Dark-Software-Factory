#### BE-1 — `GITHUB_WEBHOOK_SECRET` Not Configured

| Field         | Value                                                                                                                                                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Severity**  | 🔴 CRITICAL                                                                                                                                                                                                              |
| **Module**    | `GitHubWebhookSignatureGuard`                                                                                                                                                                                            |
| **Log Level** | ERROR                                                                                                                                                                                                                    |
| **Message**   | `GITHUB_WEBHOOK_SECRET is not configured!` (logged **twice**)                                                                                                                                                            |
| **Impact**    | Webhook HMAC signature validation is entirely bypassed. Any actor can send arbitrary payloads to the `/webhooks/github` endpoint and they will be accepted as legitimate. This is an exploitable security vulnerability. |
| **Fix**       | Set `GITHUB_WEBHOOK_SECRET` in `.env` to match the secret configured in the GitHub repo's webhook settings.                                                                                                              |

#### BE-2 — Deprecated `path-to-regexp` Wildcard Route

| Field         | Value                                                                                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Severity**  | 🟠 HIGH                                                                                                                                                                                                      |
| **Module**    | `LegacyRouteConverter`                                                                                                                                                                                       |
| **Log Level** | WARN                                                                                                                                                                                                         |
| **Message**   | `Unsupported route path: "/api/*". In previous versions, the symbols ?, *, and + were used to denote optional or repeating path parameters...`                                                               |
| **Impact**    | Fastify + `path-to-regexp` v8 no longer accepts unnamed wildcards. The auto-converter may silently mis-match requests. Wildcard catch-all is critical for the CORS proxy middleware and Swagger passthrough. |
| **Fix**       | Rename the route from `/api/*` to `/api/*path` in whichever controller/middleware defines it.                                                                                                                |

#### BE-4 — Prisma `execution.update()` Fails on Startup

| Field         | Value                                                                                                                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Severity**  | 🟠 HIGH                                                                                                                                                                                                                         |
| **Module**    | `PtyExecutionService`                                                                                                                                                                                                           |
| **Log Level** | WARN (via `prisma:error`)                                                                                                                                                                                                       |
| **Message**   | `Invalid prisma.execution.update() invocation — No record was found for an update`                                                                                                                                              |
| **Impact**    | On startup, `PtyExecutionService` tries to assign a container ID to an execution that no longer exists in the database. The operation fails silently; the affected execution remains orphaned with a stale container reference. |

#### FE-14 — Duplicate API Calls (2–6× per Page Navigation)

| Field          | Value                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

#### FE-16 — `useEffect([token])` Dependency Is Not Reactive

| Field          | Value                                                                                                                                                                                                                                                                                         |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Severity**   | 🟡 MEDIUM                                                                                                                                                                                                                                                                                     |
| **File**       | `App.tsx` — `Dashboard` component, line 248                                                                                                                                                                                                                                                   |
| **Code**       | `const token = localStorage.getItem('access_token') \|\| sessionStorage.getItem('access_token') \|\| ''` (line 101) then `useEffect(() => { fetchData(); }, [token])`                                                                                                                         |

## 11. Key Observations & Edge Cases

### Auth Race Condition (401 Errors on Fast Navigation)

The backend log contains several `401 Authentication required` errors that appear immediately after page navigation before any intentional unauthenticated request. These are **not** caused by missing tokens — the user is logged in. They occur because:

- `AppContent` re-evaluates `isLoading` on every navigation
- During the brief `isLoading = true` window, some components (especially those outside `ProtectedRoute`) fire API requests before the auth check completes
- The token exists in storage but the Axios interceptor hasn't re-attached it yet during the re-evaluation cycle

**Evidence from backend log:**

```
[b40481f2][5f40bed4] Exception caught: Authentication required   statusCode: 401
[09186d2c][8180157a] Exception caught: Authentication required   statusCode: 401
```

**Impact:** These errors are intermittent and self-resolving (the next request succeeds), but they pollute error tracking (Sentry) and could trigger false-positive alerts in production monitoring.

**Fix:** Ensure all API-calling hooks check `isAuthenticated` before firing, or use React Query's `enabled: !!user` guard. Consider wrapping the entire `AppContent` render in a single auth gate that renders `null` (not a spinner) during the re-evaluation window so child components never mount mid-check.
